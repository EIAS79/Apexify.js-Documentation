# Canvas & `createCanvas` — overview {#00-create-canvas-overview}

<Callout tone="info" title="Core Node canvas entry point">
`await painter.createCanvas(config[, painterOpts])` allocates an `@napi-rs/canvas` surface, paints configured backgrounds and effects, and returns PNG bytes plus the effective canvas configuration.
</Callout>

<Prerequisites>
- Apexify.js 6.0.0 installed in a Node runtime.
- An `ApexPainter` instance configured for buffer output.
- Explicit width and height for predictable production output unless an inherited image/video source determines them.
</Prerequisites>

## Minimal workflow

<Steps title="Create a canvas">
1. Import `ApexPainter` from `apexify.js`.
2. Create a painter with buffer output.
3. Call `createCanvas` with explicit dimensions and one primary fill.
4. Use `buffer` as the PNG output or composite additional image/text/chart content.
</Steps>

## Return value (`CanvasResults`)

<ComparisonTable leftLabel="Field" rightLabel="Meaning" rows={[{"feature":"buffer","left":"Buffer","right":"PNG bytes for saving, output, or later composition"},{"feature":"canvas","left":"CanvasConfig","right":"Effective configuration reference after inherited sizing or other mutations"}]} />

<Callout tone="warning" title="Configuration mutation">
The returned `canvas` value is the configuration reference used by the creator. Features such as inherited background sizing can update effective width or height.
</Callout>

## Paint architecture

<ArchitectureDiagram diagram="CanvasConfig → validation → surface allocation → backgrounds/layers → clip and transforms → shadow/stroke → PNG buffer" caption="High-level createCanvas pipeline" />

<Details summary="Primary fill rule">
Use only one primary fill among `colorBg`, `gradientBg`, and `customBg`. Additional layering concerns belong in the dedicated background-layer options.
</Details>

## Runnable example

<ExampleCard title="640 × 360 dark canvas" description="A minimal deterministic canvas suitable for subsequent composition.">
```typescript
import { ApexPainter } from 'apexify.js';
const painter = new ApexPainter({ type: 'buffer' });
const { buffer } = await painter.createCanvas({
  width: 640,
  height: 360,
  colorBg: '#020617',
});
```
</ExampleCard>

<ExampleSteps title="What happens next">
1. `createCanvas` validates the configuration.
2. The canvas surface is allocated.
3. Configured background and effect stages are applied.
4. The result exposes PNG `buffer` output for saving or composition.
</ExampleSteps>
