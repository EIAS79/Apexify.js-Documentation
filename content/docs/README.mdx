# Apexify.js documentation {#readme}

This site documents the staged **Apexify.js 6.0.0** Node/server package artifact and is tested against an exact repository commit. npm `latest` remains 5.4.5 until 6.0.0 is explicitly published.

The documentation hierarchy is intentionally split between learning material and contract/reference material:

- tutorials/recipes explain workflows;
- feature guides explain domain behavior and options;
- API Reference inventories the current public package surface;
- Advanced contains runtime policy, security, performance, migration, and composition/media depth;
- Internals/changelog pages are historical/developer context and must not override current runtime/export truth.

## Source of truth

For current behavior, use this precedence:

1. current merged package source/runtime implementation;
2. current package exports and generated declarations;
3. packed-package consumer fixtures/tests;
4. this API Reference and current guides;
5. historical internals/changelog material.

If a historical page contradicts a current API-reference page, the historical page is not the runtime contract.

The current public package exposes only declared package exports (`apexify.js`, type-only `apexify.js/types`, and `apexify.js/package.json`). Do not teach or depend on internal `lib-next/*` / `dist/*` paths.
