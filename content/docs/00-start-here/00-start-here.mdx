# Start here {#00-start-here}

Welcome to **Apexify.js** — a Node/server library for programmatic PNG/image composition, text, charts, GIFs, FFmpeg-backed video, procedural audio, scenes, templates, and batch/output workflows.

> **Release target:** these docs describe **Apexify.js 6.0.0** and are verified against an exact package commit. During the npm release cutover, confirm the registry resolves to `6.0.0` before relying on v6-specific behavior: `npm view apexify.js version`.

---

## Requirements for 6.0.0

- **Node.js 22.x, 24.x, or 26.x**
- **npm 10+**
- **FFmpeg + ffprobe only for video/FFmpeg features**
- TypeScript is optional; package declarations ship for ESM and CommonJS consumers

Apexify.js 6 is a **Node/server package**. Browser-native, React/Next, Render-IR/ARS, native browser animation, AI-assistant, and distributed-renderer packages are not current shipped 6.0 APIs.

---

## Published npm install

```bash
npm install apexify.js
```

These docs target 6.0.0. During the release cutover, verify the resolved version with `npm view apexify.js version` or `npm ls apexify.js` before deployment.

---

## ESM and CommonJS

```js
// ESM
import { ApexPainter } from "apexify.js";

// CommonJS
const { ApexPainter } = require("apexify.js");
```

`apexify.js/types` is a **type-only** subpath. Do not import internal source or `dist/*` paths.

---

## Smallest v6 example

```ts
import { writeFile } from "node:fs/promises";
import { ApexPainter } from "apexify.js";

const painter = new ApexPainter({ type: "buffer" });
const canvas = await painter.createCanvas({
  width: 640,
  height: 360,
  colorBg: "#0f172a",
});

const png = await painter.createText(
  {
    text: "Apexify.js",
    x: 320,
    y: 180,
    font: { size: 48, family: "Arial" },
    fill: { color: "#ffffff" },
    placement: { textAlign: "center", textBaseline: "middle" },
  },
  canvas,
);

await writeFile("out.png", png);
```

`createCanvas()` returns `CanvasResults` (`buffer` plus canvas metadata). Normal raster rendering methods return PNG `Buffer`s; constructor output type is applied explicitly through `toOutput()`.
