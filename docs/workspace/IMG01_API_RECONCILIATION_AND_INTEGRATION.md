## Reconciliation (no unsupported claims)

- Seven conic gradient startAngle paths: case B. Pinned compiled renderer takes startAngle and calls ctx.createConicGradient with it. Nevertheless, the pinned native createImage PNG pixel test comparing 0 versus 180 degrees produced identical raw pixels for a rendered conic shape. This is a measured ineffective behavior. The shared Image/Canvas gradient editor correctly does NOT expose a falsely working start-angle slider. Model validation/round-trip still accepts the published field. All seven remain PARTIAL.
- Seven gradient repeat paths: cases B/C. Pinned union accepts repeat/reflect/no-repeat only for linear or radial gradient variants; conic forbids this field. The shared UI and validator honor this discrimination, but pinned raster reflect/repeat behavior is not reliably proven for all widths/geometry (prior S14 evidence: narrow gradients at large output sizes). All seven remain PARTIAL; no generic conic repeat control is created.
- Two ImageFilter.radius paths: case C. Radius is an effective field only for gaussianBlur, motionBlur and radialBlur. The 17-filter union is discriminant-specific, but the static inventory flattens its radius identity. UI/validation allow radius only for the three blur families, rejecting sharpen/grayscale and other discriminants. These records remain PARTIAL at the flattened path level; no unrelated no-op radius control is created.
- Four shadow side/corner paths: UPSTREAM unchanged. shadow.borderPosition and shadow.roundedCorners in individual images and group transforms remain read-only / not claimed effective until independently visible native pixel behavior is demonstrated. The presence of similarly named border/stroke code elsewhere is not proof of shadow behavior.
- painterOpts.resolveAssetRefs: public BOOLEAN, NOT callback (pinned apex-painter/main.d.ts and batch options). Passing true opts imperative operations into built-in $ref resolution when configured; imperative calls otherwise do not auto-resolve. This is painter-call asset orchestration, not per-image Inspector data. Workspace resolves only immutable SHA-256-verified local image/mask bytes and does not grant user-configured arbitrary filesystem, URL or asset-registry resolution. Retain BLOCKED_SECURITY without falsely labeling the boolean itself a callback.
